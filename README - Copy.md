# Caravan of Flavours
## Global Spice Trading Made Simple

**Caravan of Flavours** is a premium, end-to-end B2B marketplace designed for the global spice industry. It connects small-batch organic farmers and bulk industrial producers directly with international buyers, streamlining the entire trade process from farm to facility.

### 🌟 Key Features
- **Real-Time Market Analytics:** Access live price tickers and historical data for major spices like Cloves, Turmeric, and Black Pepper.
- **Global Trade Hub:** A simplified platform for managing bulk shipments, organic harvests, and international logistics.
- **Auction System:** Integrated bidding for premium harvests and industrial lots.
- **Export Management:** Specialized tools for documentation, compliance, and multi-currency transactions.
- **Farmer & Customer Dashboards:** Dedicated interfaces for managing inventory, tracking orders, and viewing activity history.

### 🏗️ Technology Stack
- **Frontend:** Modern HTML5, Vanilla CSS, TailwindCSS, and Google Fonts (Outfit).
- **Backend:** PHP-based RESTful API for secure data handling and session management.
- **Database:** MySQL for robust storage of orders, users, and market data.
- **Integrations:** Google Identity Services (SSO), Iconify for dynamic icons, and responsive UI components.

### 🚀 Getting Started
1. Clone the repository.
2. Configure your environment variables in `.env`.
3. Set up the MySQL database using the provided schema.
4. Launch via a local PHP server or any standard web hosting environment.
